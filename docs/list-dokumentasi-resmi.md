# Daftar Dokumentasi Resmi Duitku

Dokumen ini mengumpulkan tautan resmi yang relevan untuk integrasi Duitku POP pada repository ini.

## Dokumentasi utama

- **Duitku POP:** https://docs.duitku.com/pop/id/
- **Duitku API:** https://docs.duitku.com/api/id/
- **Metode pembayaran POP:** https://docs.duitku.com/pop/id/#payment-method
- **FAQ resmi Duitku:** https://www.duitku.com/frequently-asked-questions/
- **Situs resmi Duitku:** https://www.duitku.com/

## Referensi Sandbox

- **Demo Duitku Sandbox:** https://api-sandbox.duitku.com/demoduitku/
- **Halaman demo pembayaran Sandbox:** https://sandbox.duitku.com/payment/demopage.aspx

## Aturan penggunaan sumber

1. Jadikan dokumentasi POP sebagai rujukan utama untuk kontrak integrasi POP.
2. Periksa bagian terkait pembuatan invoice, request signature, callback, status transaksi, dan metode pembayaran sebelum implementasi.
3. Jangan mengasumsikan endpoint, parameter, algoritma signature, format callback, atau status transaksi. Cocokkan dengan dokumentasi resmi yang berlaku untuk produk dan mode integrasi yang digunakan.
4. Catat tanggal pemeriksaan, bagian dokumentasi, serta bukti pengujian saat kontrak diterapkan ke kode.
5. Tautan Sandbox adalah sarana referensi/pengujian; tautan tersebut tidak membuktikan bahwa integrasi repository ini telah diuji atau berhasil.
6. Jangan memasukkan merchant API key, kredensial, atau data transaksi sensitif ke dokumentasi maupun commit.

Lihat juga [Integrasi Duitku POP](duitku-integration.md).
